# 신소재공학과 대학 면접 준비 자료

## 포함 내용
- 합성함수: 기본 개념, 계산 예시, 예상 질문
- 산·염기 중화 반응: 기본 개념, 반응식, pH, 예상 질문
- 염료감응 태양전지(DSSC): 기본 작동 원리, 구성 요소, 예상 질문
- 리플로우 공정: 기본 개념, 주요 용어, 공정 순서, 재료과학 관점, 예상 질문
- 신소재공학 전공 연계: 재료의 구조·성질·공정·응용 관점
- 참고 자료 링크

## GitHub Pages에 반영하는 방법
1. ZIP 파일의 `index.html`을 압축 해제합니다.
2. GitHub 저장소 `MODERN08200/materials-interview`를 엽니다.
3. `Add file` → `Upload files`를 선택합니다.
4. 새 `index.html`을 업로드하고 기존 파일을 교체합니다.
5. 변경 사항을 커밋합니다.
6. `Settings` → `Pages`에서 `Deploy from a branch`, `main`, `/(root)` 설정을 확인합니다.
7. 배포 후 https://modern08200.github.io/materials-interview/ 에서 확인합니다.

이 자료는 기본 개념 설명과 대학 면접 답변 연습을 함께 제공하는 정적 HTML 웹사이트입니다.
