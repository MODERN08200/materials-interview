# 신소재공학과 대학 면접 준비 자료 웹사이트

## 적용 방법
1. 이 압축 파일을 내려받아 압축을 풉니다.
2. GitHub 저장소 https://github.com/MODERN08200/materials-interview 에 접속합니다.
3. **Add file → Upload files**를 선택합니다.
4. 새 `index.html`을 업로드해 기존 파일을 교체하고 Commit changes를 누릅니다.
5. **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)` 설정을 확인합니다.

## 사이트 주소
https://modern08200.github.io/materials-interview/

## 변경 사항
- 메뉴에서 파트를 선택하면 해당 파트 내용만 표시됩니다.
- 합성함수, 중화 반응, DSSC, 리플로우 공정, 전공 연계 및 참고 자료를 포함합니다.
- 모바일 화면에도 대응하며, 각 파트의 참고 링크는 새 탭에서 열립니다.
