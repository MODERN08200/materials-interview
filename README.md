# 신소재공학과 대학 면접 준비 사이트

## 포함 내용
- 합성함수
- 산과 염기의 중화 반응
- 염료감응 태양전지(DSSC)
- 신소재공학 전공 연계 및 참고 자료

## GitHub Pages 배포
1. 저장소 https://github.com/MODERN08200/materials-interview 에 접속합니다.
2. Add file → Upload files 를 선택합니다.
3. 압축을 푼 뒤 `index.html` 파일을 업로드하고 Commit changes를 누릅니다.
4. Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main`, Folder를 `/(root)`로 선택하고 Save 합니다.
5. 배포 후 https://modern08200.github.io/materials-interview/ 에서 확인합니다.

현재 ChatGPT의 GitHub 연결은 저장소 파일을 직접 쓰는 작업이 거부되어, 이 패키지를 업로드하는 방식으로 제공합니다.
